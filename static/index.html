How this works

The model learned from thousands of hourly readings of one combined cycle power plant. Each reading has four measurements of the surroundings and the electricity the plant produced at that time.

It is a random forest: many decision trees that vote on the answer. A straight-line model was off by about 3.6 MW on average, a neural network built from scratch for this project by about 2.9 MW, and the random forest by about 2.3 MW. That is why the random forest runs this service.

The model only knows this one plant and the conditions in its training data. Outside those conditions, its answer is closer to a guess, which is what the warning on the result is for.

Is the incoming data still like the training data?

Every request sent to the API is logged. This check compares the most recent logged requests (up to 500) with the readings the model learned from. If they look very different, for example after a run of much hotter weather, predictions may become less reliable.

The sliders above only preview a prediction. They are not logged.
